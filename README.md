# 3d-style-atlas pilot

Each subfolder is a HyperFrames project built on `Skills/3d-style-atlas`. The full API is in `Skills/3d-style-atlas/references/kit-api.md`.

- `00-smoke/`: a 5 s neutral-style smoke test (primitives, shadows, camera swing, label, SFX).
  - `scene.config.js` holds the plain data (beats, camera, objects, score). `scene.js` holds the Three code. `index.html` is the composition.
  - `_atlas/` is a generated copy of the kit. Don't edit it; re-run `sync-kit.mjs` instead.
  - `sfx.wav` is generated by `render-sfx.mjs` and is byte-deterministic. `scene.spec.json` is generated by `export-spec.mjs`.
  - `renders/00-smoke.mp4` is the verified render. `renders/checks/t*.jpg` are the frames used for the visual check.

To rebuild:
```bash
SK="$HOME/Library/CloudStorage/Dropbox/D Second Brain/Skills/3d-style-atlas"
cd 00-smoke && node "$SK/scripts/sync-kit.mjs" . && node "$SK/scripts/render-sfx.mjs" . \
  && npx hyperframes lint && npx hyperframes render --output renders/00-smoke.mp4 --fps 30
```
To start a new scene, copy `00-smoke/` (without `_atlas/` or `renders/`), edit `scene.config.js` and `scene.js`, and then re-sync.
